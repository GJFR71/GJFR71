## 👶 [Predição de Baixo Peso ao Nascer](https://github.com/GJFR71/predicao-baixo-peso-ao-nascer)

Projeto de análise preditiva aplicado a dados de saúde, com foco na identificação de gestantes com maior risco de ocorrência de baixo peso ao nascer.

Foram comparadas diferentes abordagens de Machine Learning, com atenção não apenas ao desempenho estatístico, mas também à utilidade prática do modelo.

**Técnicas:** Elastic Net, Random Forest, XGBoost, Ridge, Lasso, ROC, Lift, criação de KPIs e ajuste estratégico do ponto de corte.

📌 **Destaque:** integração entre modelagem estatística, avaliação preditiva e comunicação dos resultados para apoiar decisões em saúde pública.

# 🔬 Pesquisa acadêmica

Atualmente desenvolvo pesquisa de **Mestrado em Ciência da Computação**, envolvendo Estatística e processamento de imagens.

### Calibração estatística de parâmetro para pré-processamento de imagens de ultrassom mamário

A pesquisa investiga uma estratégia estatística reprodutível para seleção de um parâmetro global de filtragem, buscando equilibrar:

* redução de ruído;
* preservação de estruturas;
* contraste entre regiões;
* manutenção de bordas;
* desempenho em tarefas posteriores de segmentação.

O trabalho combina **Estatística Aplicada, otimização, processamento digital de imagens e avaliação quantitativa de desempenho**.

# 🎯 Como trabalho com dados

Mais do que aplicar algoritmos ou construir dashboards, procuro estruturar a análise a partir do problema que precisa ser resolvido.

**Problema → Dados → Análise → Modelo → Interpretação → Decisão**

O objetivo é produzir soluções que sejam tecnicamente consistentes, compreensíveis e úteis para quem precisa tomar decisões.
